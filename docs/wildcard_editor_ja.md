# SAX Wildcard Editor（Autocomplete++ 用）

SAX_Bridge の **SAX Wildcard Editor** ノードは、Autocomplete++ が読み込める `.txt` ワイルドカードを編集するための独立した管理画面を開きます。SAX Text Catalog V2 のデータ・UI には依存しません。ノードの実行は不要です。

1. `SAX/Bridge/Utility → SAX Wildcard Editor` を追加。
2. **ワイルドカードを編集** で画面を開き、保存先 → フォルダー → ファイルの階層一覧から選択、または **＋ 新規作成** を押します。フォルダーに配下のファイル数を表示し、一括開閉できます。ファイル名・フォルダー名・保存先の検索は一致した経路を自動展開します。
3. 右側で保存先とファイル名（例: `clothing/dresses`）を指定。ファイル名に `.txt` を付けなくても保存時に付与されます。
4. 候補は **1行に1つ** 記述します。候補の追加はカーソルのある行または選択行の後ろへ挿入します。複数行を選択してまとめて削除・上下移動でき、移動後もその行を選択します。**保存** または **Ctrl+S／Cmd+S** で反映されます。保存中は本文・保存先・ファイル名を一時的に操作できなくなります。
5. **？ 書式ヘルプ** またはノード上の **書式ヘルプ** から短い実例を確認できます。詳しい仕様は [Autocomplete++ 公式説明](https://github.com/michikora/ComfyUI-Autocomplete-Plus-Plus/blob/main/README_jp.md)。

## ファイル形式

```text
# outfits
red dress
blue dress
{3::white dress | 1::black dress}
__style/casual__
```

ファイルを `clothing/dresses.txt` として保存した場合、プロンプト中の `__clothing/dresses__` から参照します。空行・`#` コメント行は抽選対象から除かれます。改行・コメントは編集で保持され、保存時に自動削除されません。

保存先として選べるのは、Autocomplete++ が探索する `ComfyUI/wildcards/`、既存の `custom_nodes/*/wildcards/`、Autocomplete++ の `tags/wildcards/` です。任意の OS 絶対パスへの書き込みは安全上許可しません。保存先内部の相対パスとファイル名は選べます。

- 別名保存は元ファイルを残します。既にある別名ファイルを知らずに上書きすることはありません。
- 他の編集による同時変更をハッシュで検出します。保存時に衝突した場合は勝手に上書きしません。
- 同名ファイルが複数の検索先に存在すると優先順位の高い方が使用されるため、一覧と保存完了時に警告します。
- UTF-8テキストのみ、1ファイル最大2 MiB、一覧は最大10,000ファイルです。
- 画面にはスクロール位置付近の行だけを描画します。従来の「先頭300件のみ」の制限はなく、取得した全ファイルへアクセスできます。検索を解除すると通常の開閉状態へ戻ります。
- 各階層はフォルダーを先に表示し、数字を含む名前は `dir2 → dir10` の自然順で並べます。保存先は探索の優先順位順に表示します。
- ファイルを持たないフォルダー・保存先は一覧に表示しません。空の保存先も新規作成の保存先欄から選べます。
- 開いているファイルは「ファイルを削除」から、保存先とファイル名を確認して削除できます。未保存の変更も破棄され、元に戻せません。同名の別ファイルやフォルダー自体は削除しません。読み込み後に外部で変更された場合は削除を拒否し、本文を保持します。
- ファイル一覧は上下キー・Home／Endで移動、左右キーで開閉・親へ移動、Enterで選択できます。Escapeで画面を閉じ、未保存の変更があれば破棄の確認を表示します。
- ファイル名の下にプロンプト用の `__folder/name__` を表示します。同名ファイルの優先順位警告は保存先ごとに保持します。
- 本文欄はAutocomplete++のタグ補完を利用します。候補は編集画面の前面に表示し、候補をEscapeで閉じてもエディターは閉じません。エディターを閉じると、その本文欄の補完候補も解除します。
- 保存・削除後に、操作したブラウザーのAutocomplete++の補完一覧・内容キャッシュ・展開用データを再取得します。「一覧更新」からも再試行でき、通常はブラウザーの再読み込みが不要です。
- ファイル保存と展開データ更新は別に状態を表示します。更新失敗時も保存済みファイルと最後に正常取得した展開データは保持し、再試行またはブラウザーの再読み込みを案内します。自動更新には対応するAutocomplete++が必要です。
- Autocomplete++の「前回選択を固定」モードは同じSeedの選択を保持するため、保存した内容から選び直す場合はSeedを変更してください。別のブラウザー・タブのキャッシュは、この操作では更新しません。
